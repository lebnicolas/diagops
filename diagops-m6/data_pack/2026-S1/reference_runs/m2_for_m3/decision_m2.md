# Décision de référence M2

**Décision : utilisable sous conditions.**

Les trois tables préparées sont exploitables pour les travaux de M3 :
identifiants uniques, relations vérifiées, domaines fermés respectés et
anomalies tracées. 35 lignes de quarantaine documentent les
exclusions, neutralisations et normalisations.

## Conditions attachées

1. Les champs neutralisés ne doivent pas être traités comme des valeurs
   observées.
2. Les durées d'arrêt supérieures à quatorze jours restent à expertiser avant
   toute utilisation quantitative.
3. Les valeurs manquantes de `parts_cost_eur` sont concentrées sur un site : les
   comparaisons entre sites doivent le mentionner.
4. Les catégories peu représentées ne permettent pas de conclusion catégorique.
5. La pseudonymisation appliquée aux notes est une mesure de minimisation, pas
   une anonymisation.

Cette décision assure la continuité pédagogique. Elle ne remplace ni
l'évaluation ni la production personnelle de M2.
